# أرشيف قسم الدعم والإسناد — الدفاع المدني

نسخة من موقع «أرشيف قسم الدعم والإسناد» المبني في Claude، بنفس الصفحة والتصميم والأقسام: لوحة اليوم، الآليات، المعدات، المستودعات، الرغاوي والمحروقات، الكادر البشري، المعاملات، الملفات التعريفية، تقارير الرجيع، أعطال المبنى.

هذه النسخة **للعرض فقط**. الإضافة والتعديل تتم في موقع Claude، ثم تُزامَن البيانات إلى هنا.

## النشر على GitHub Pages

عند كل تحديث للفرع الرئيسي يبني GitHub نسخة ثابتة من الموقع (`npm run build:static`) وينشرها تلقائيًا على `https://civ99fad.github.io/SSD/`.

- التفعيل مرة واحدة: من إعدادات المستودع **Settings ← Pages** اختر **Source: GitHub Actions**.
- كلمة المرور تُؤخذ من السر `SITE_PASSWORD` في **Settings ← Secrets and variables ← Actions** إن وُجد، وإلا من `data/settings.json`.
- **تنبيه:** لا يوجد خادم في هذه النسخة، فكلمة المرور حماية شكلية فقط. كل الصور والمستندات يمكن فتحها مباشرة لمن يعرف الرابط، والمستودع العام يكشف كل الملفات.

## التشغيل على جهازك أو على Render

1. ثبّت **Node.js** (الإصدار 18 أو أحدث) من https://nodejs.org (مرة واحدة فقط).
2. شغّل الموقع:
   - **ويندوز:** انقر مرتين على `تشغيل الموقع (ويندوز).bat`
   - **ماك:** انقر مرتين على `تشغيل الموقع (ماك).command`
   - أو من الطرفية: `npm start`
3. افتح المتصفح على **http://localhost:3000**. كلمة المرور الافتراضية هي **1234**.

في هذا الوضع يحمي الخادم البيانات والملفات فعلًا: لا تُفتح إلا بعد إدخال كلمة المرور.

للنشر على Render: الملف `render.yaml` جاهز. من https://render.com سجّل الدخول بحساب GitHub، ثم **New → Blueprint**، واختر المستودع `civ99fad/SSD`، وأدخل كلمة المرور في `SITE_PASSWORD` ثم اضغط **Apply**.

## تغيير كلمة المرور

نفّذ `npm run set-password -- 5678`، أو عدّل الملف `data/settings.json`:

```json
{ "password": "كلمة-المرور-الجديدة" }
```

على GitHub Pages و Render يُفضَّل ضبطها من `SITE_PASSWORD` بدلًا من الملف، لأن المستودع عام.

## هيكل المشروع

```
site/
├── page.html        ← صفحة موقع Claude كما هي (لا تُعدَّل يدويًا)
└── shim.js          ← يشغّلها خارج Claude: يقرأ البيانات من الملفات ويضيف كلمة المرور
data/
├── db/              ← بيانات موقع Claude: ملف JSON لكل مجموعة (vehicles.json, equipment.json, ...)
│   └── files/       ← نماذج الاستلام والتسليم (Word)
├── blobs/           ← الصور والمستندات، واسم كل ملف هو معرّفه في موقع Claude
└── settings.json    ← كلمة المرور
tools/
├── site.js          ← يجمّع الصفحة والبيانات (يستخدمه الخادم والبناء)
├── build-static.js  ← بناء نسخة GitHub Pages في _site/
└── set-password.js
server.js            ← الخادم المحلي / Render
```

عند تحديث `site/page.html` بنسخة أحدث من موقع Claude، يطبّق `tools/site.js` عليها تعديلين صغيرين تلقائيًا. إن تغيّر السطران المستهدفان في الصفحة يتوقف البناء برسالة توضّح السبب.

## مزامنة البيانات من موقع Claude

اطلب من Claude مزامنة الموقع: يسحب البيانات الحالية من موقع Claude إلى `data/db/`، والملفات الجديدة إلى `data/blobs/`، ونسخة الصفحة الأحدث إلى `site/page.html`، ثم يرفع التغييرات فيُنشر الموقع تلقائيًا.

> **تنبيه:** الموقع يحتوي بيانات شخصية للأفراد ومستندات رسمية.
