# أرشيف قسم الإسناد — الدفاع المدني

موقع محلي لأرشفة وعرض بيانات الآليات والمستودعات. يعمل على جهازك فقط، ولا يحتاج إنترنت إلا لتحميل خط Tajawal.

## التشغيل

1. ثبّت **Node.js** (الإصدار 18 أو أحدث) من https://nodejs.org (مرة واحدة فقط).
2. شغّل الموقع:
   - **ويندوز:** انقر مرتين على `تشغيل الموقع (ويندوز).bat`
   - **ماك:** انقر مرتين على `تشغيل الموقع (ماك).command`
   - أو من الطرفية: `npm start`
3. افتح المتصفح على **http://localhost:3000**. كلمة المرور الافتراضية هي **1234**.

لا يلزم تثبيت أي مكتبات إضافية (`npm install` غير مطلوب).

## تغيير كلمة المرور

عدّل الملف `data/settings.json`:

```json
{ "password": "كلمة-المرور-الجديدة" }
```

أو نفّذ الأمر: `npm run set-password -- 5678`. التغيير يسري فورًا ولا يحتاج إعادة تشغيل.

## الصلاحيات

- **الفريق:** يدخل بكلمة المرور، ويعرض ويبحث ويفلتر فقط. لا توجد في الموقع أي أزرار للإضافة أو التعديل أو الحذف.
- **المسؤول (أنت):** يدير البيانات من مجلد `data/` مباشرة. كل تعديل يظهر عند تحديث الصفحة، بدون إعادة تشغيل.

## هيكل البيانات

```
data/
├── settings.json              ← كلمة المرور
├── warehouses/
│   ├── 1.json                 ← مستودع (الاسم، تاريخ التحديث، الأصناف)
│   └── ...
└── vehicles/
    └── 998/                   ← مجلد لكل آلية (اسم المجلد = رقم الآلية)
        ├── info.json          ← البيانات الأساسية + الجرد + السجل
        ├── photos/            ← صور الآلية الخارجية (jpg / png / webp)
        ├── contents/          ← صور محتويات الآلية
        ├── documents/         ← مستندات السجل (PDF أو صور)
        └── form/              ← نموذج الاستلام والتسليم (Word)
```

**الصور تُعرض تلقائيًا:** أي صورة توضع في `photos/` أو `contents/` تظهر في المعرض مباشرة. الصور مرتبة حسب اسم الملف، وأول صورة في `photos/` هي الصورة المصغّرة في قائمة الآليات. لذلك سمّها مثلًا `01.jpg` و`02.jpg` وهكذا.

### ملف `info.json`

```json
{
  "name": "مرسيدس مزدوجة",
  "plate": "أ ح ط 8147",
  "make": "مرسيدس",
  "model": "2004",
  "code": "0/1",
  "entity": "الإسناد والاحتياط",
  "warehouse": "1",

  "inventoryDate": "1448-03-26",
  "inventory": [
    ["سفتي", 1],
    ["ونان", 1]
  ],
  "inventoryNotes": ["ملاحظة تظهر أسفل جدول الجرد"],

  "history": [
    { "type": "استلام", "date": "1448-04-06", "description": "وصف مختصر", "file": "استلام-1448-04-06.pdf" }
  ]
}
```

- **التواريخ هجرية** بصيغة `سنة-شهر-يوم` (مثل `1448-03-26`)، ويعرضها الموقع هكذا: «٢٦ ربيع الأول ١٤٤٨هـ».
- **`type` في السجل** يأخذ إحدى القيم: `استلام` (أخضر)، `تسليم` (ذهبي)، `محضر` (رمادي).
- **`file`** هو اسم الملف داخل مجلد `documents/`.
- **`warehouse`** هو رقم المستودع (اسم ملفه في `data/warehouses/` بدون `.json`)، ويُستخدم في فلتر «المستودع».

### إضافة آلية جديدة يدويًا

```
npm run new-vehicle -- 999
```

ينشئ هذا الأمر المجلد `data/vehicles/999/` بكل مجلداته الفرعية، مع ملف `info.json` من القالب. بعدها عدّل الملف وضع الصور والملفات في أماكنها، ثم نفّذ `npm run check` لفحص البيانات والتأكد من خلوّها من الأخطاء.

## النشر على الإنترنت (Render)

الملف `render.yaml` جاهز. من https://render.com: سجّل الدخول بحساب GitHub، ثم **New → Blueprint**، واختر المستودع `civ99fad/SSD` والفرع `claude/civil-defense-archive-site-y3ue1n`. أدخل كلمة المرور في `SITE_PASSWORD` ثم اضغط **Apply**. كلمة المرور على الاستضافة تُغيَّر من **Environment** في لوحة Render.

## أقسام الموقع

الآليات، المستودعات، الملفات التعريفية، تقارير الرجيع، أعطال المبنى، الكادر البشري، المعاملات، الرغاوي والمحروقات.

- بيانات الآليات في `data/vehicles/<رقم>/info.json` مع صورها ومستنداتها.
- بيانات باقي الأقسام في `data/records/*.json`، ومرفقاتها (PDF والصور) في `data/files/`.
- حقل `status` للآلية يأخذ: `ready` جاهزة، `down` متعطلة بالمقر، `maint` في الصيانة، `away` مدعومة لجهة أخرى.

> **تنبيه:** الموقع يحتوي بيانات شخصية للأفراد. أبقِ مستودع GitHub **خاصًا (Private)**، ولا تشغّل الموقع على شبكة عامة.

## ملاحظات

- الجلسات محفوظة في ذاكرة الخادم، لذلك يلزم إعادة تسجيل الدخول بعد إعادة تشغيل الموقع أو بعد مرور 12 ساعة.
- الموقع مخصّص للتشغيل المحلي. قبل نشره على شبكة أو على الإنترنت يلزم تشغيله عبر HTTPS واختيار كلمة مرور قوية.
