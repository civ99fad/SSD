# بوابة الإدارة العامة للدفاع المدني

تفتح **البوابة** مباشرة بلا كلمة مرور، ويختار منها المستخدم الجهة. **كل جهة لها كلمة مرور خاصة** تُطلب عند دخولها (الافتراضية لكل الجهات **1234**).

ترتيب البوابة:

- **المراكز**: البلد، شراف، المنتزه، الصناعية، العزيزية، الدائري، أجا، الجبل، التدخل بحوادث المواد الخطرة (`balad.html`، `sharaf.html`، …، `hazmat.html`). نفس الصفحة بكل ميزاتها، ولكل مركز بياناته المستقلة في `data/units/<المركز>/db`.
- **قسم الدعم والإسناد** (`isnad.html`، آخر البوابة): أرشيف القسم، وأصله موقع «أرشيف قسم الدعم والإسناد» المبني في Claude.

**لوحة مدير الإدارة** (`manager.html`، أعلى البوابة، بكلمة مرور خاصة `manager`) تجمع كل الجهات في صفحة واحدة:
- مؤشرات عامة: الجاهزية الإجمالية للآليات، حالة الجهات، الآليات غير الجاهزة، الوايتات الجاهزة، القوة المناوبة الآن، المهام المتأخرة وأعطال المباني.
- تنبيهات تحتاج قرارًا (نقص الورديات اليوم وغدًا، جاهزية منخفضة، لا يوجد وايت جاهز، مهام متأخرة).
- بطاقة لكل مركز بحالته (جاهز / يحتاج متابعة / حرج)، مع ترتيب «الأحرج أولًا» أو «الأقل جاهزية»، والضغط عليها يفتح المركز مباشرة.
- الآليات غير الجاهزة في كل الجهات مع زر «نسخ رسالة للصيانة»، وتحركات الدعم بين الجهات، والمهام المتأخرة والقريبة، وجدول مقارنة.
- «نسخ الملخص» للواتساب، و«طباعة التقرير»، وتحديث تلقائي كل ٥ دقائق.
- الدخول للوحة المدير يفتح كل الجهات بدون كلماتها حتى تسجيل الخروج.

أقسام كل جهة: لوحة اليوم، قائمة المهام، الآليات، المعدات، المستودعات، الرغاوي والمحروقات، الكادر البشري، المعاملات، الملفات التعريفية، تقارير الرجيع، أعطال المبنى.

- **الفريق:** يدخل بكلمة مرور الجهة ويعرض ويبحث فقط.
- **المسؤول:** يفعّل التعديل بمفتاح GitHub فتظهر له كل أزرار الإضافة والتعديل والحذف ورفع الصور والملفات.

**المستودع هو المصدر الأساسي للبيانات.** موقع Claude الأصلي لا يتحدّث تلقائيًا بالتعديلات التي تتم هنا.

## تفعيل التعديل (للمسؤول)

1. أنشئ مفتاحًا من GitHub: **Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token**.
   - **Repository access:** Only select repositories ← `civ99fad/SSD`
   - **Permissions ← Repository permissions ← Contents:** Read and write
   - اختر مدة صلاحية مناسبة (مثلًا سنة)، ثم انسخ المفتاح.
2. افتح الموقع، واضغط **تفعيل التعديل (للمسؤول)** في شاشة الدخول، والصق المفتاح ثم **حفظ المفتاح**.
3. ادخل بكلمة المرور كالعادة. ستظهر أزرار التعديل في كل الأقسام، واسمك في أسفل القائمة مع «صلاحية التعديل».

- المفتاح يُحفظ في متصفح هذا الجهاز فقط. لإلغائه: **إيقاف التعديل** في شاشة الدخول، أو احذفه من GitHub.
- كل حفظ يُرفع للمستودع كتعديل (commit) في `data/db/` أو `data/blobs/`، ويُعاد نشر الموقع تلقائيًا. التعديل يظهر لك فورًا، وللفريق بعد دقيقة إلى دقيقتين.
- حد حجم الملف المرفوع 20 ميجابايت (مثل موقع Claude).

## النشر على GitHub Pages

عند كل تحديث للفرع الرئيسي يبني GitHub نسخة ثابتة من الموقع (`npm run build:static`) وينشرها تلقائيًا على `https://civ99fad.github.io/SSD/`.

- التفعيل مرة واحدة: من إعدادات المستودع **Settings ← Pages** اختر **Source: GitHub Actions**.
- كلمات المرور تُؤخذ من `data/settings.json` (انظر «تغيير كلمة المرور»)، أو من السر `SITE_PASSWORD` في **Settings ← Secrets and variables ← Actions** إن وُجد.
- **تنبيه:** لا يوجد خادم في هذه النسخة، فكلمة المرور حماية شكلية فقط. كل الصور والمستندات يمكن فتحها مباشرة لمن يعرف الرابط، والمستودع العام يكشف كل الملفات.

## التشغيل على جهازك أو على Render

1. ثبّت **Node.js** (الإصدار 18 أو أحدث) من https://nodejs.org (مرة واحدة فقط).
2. شغّل الموقع:
   - **ويندوز:** انقر مرتين على `تشغيل الموقع (ويندوز).bat`
   - **ماك:** انقر مرتين على `تشغيل الموقع (ماك).command`
   - أو من الطرفية: `npm start`
3. افتح المتصفح على **http://localhost:3000**. كلمة مرور كل جهة الافتراضية هي **1234**.

في هذا الوضع يحمي الخادم البيانات والملفات فعلًا: بيانات كل جهة لا تُفتح إلا بعد إدخال كلمة مرورها.

للنشر على Render: الملف `render.yaml` جاهز. من https://render.com سجّل الدخول بحساب GitHub، ثم **New → Blueprint**، واختر المستودع `civ99fad/SSD`، وأدخل كلمة المرور في `SITE_PASSWORD` ثم اضغط **Apply**.

## تغيير كلمة المرور

- لجهة واحدة: `npm run set-password -- 5678 sharaf` (رمز الجهة: `balad`، `sharaf`، `muntazah`، `sinaiya`، `aziziya`، `dairi`، `aja`، `jabal`، `hazmat`، `isnad`، ولوحة المدير `manager`).
- لكل الجهات التي ليس لها كلمة خاصة: `npm run set-password -- 5678`.

أو عدّل الملف `data/settings.json` مباشرة:

```json
{ "password": "1234", "units": { "sharaf": "5678", "isnad": "9012" } }
```

الأولوية: `SITE_PASSWORD_<الجهة>` (مثل `SITE_PASSWORD_SHARAF`) ثم `units` في الملف ثم `SITE_PASSWORD` ثم `password` ثم 1234. على Render يُفضَّل ضبطها من متغيرات البيئة بدلًا من الملف، لأن المستودع عام.

## قائمة المهام

لكل جهة قائمة مهام: نوع المهمة، تاريخ البدء، تاريخ الانتهاء، المكلف بالمهمة، وملاحظات. الحالة تُحسب تلقائيًا (لم تبدأ، جارية، متأخرة، منجزة)، ويظهر عدد المتأخرة على زر القائمة. المسؤول يضيف ويعدّل ويحذف ويعلّم المهمة منجزة، وتُحفظ في `tasks.json` داخل بيانات الجهة.

## هيكل المشروع

```
site/
├── portal.html      ← البوابة: اختيار الجهة (بلا كلمة مرور)
├── manager.html     ← لوحة مدير الإدارة: جاهزية كل الجهات
├── page.html        ← صفحة الجهة (أصلها من موقع Claude، وتُطوَّر هنا)، تُبنى منها صفحة لكل جهة
└── shim.js          ← يشغّلها خارج Claude: القراءة من الملفات، والرجوع للبوابة، والحفظ في GitHub للمسؤول
data/
├── db/              ← بيانات قسم الدعم والإسناد: ملف JSON لكل مجموعة (vehicles.json, equipment.json, ...)
├── units/<المركز>/db/ ← بيانات كل مركز بنفس الترتيب
│   └── files/       ← نماذج الاستلام والتسليم (Word)
├── blobs/           ← الصور والمستندات، واسم كل ملف هو معرّفه في موقع Claude
└── settings.json    ← كلمات المرور (العامة و units لكل جهة)
tools/
├── site.js          ← قائمة الجهات (UNITS) وتجميع الصفحات والبيانات (يستخدمه الخادم والبناء)
├── build-static.js  ← بناء نسخة GitHub Pages في _site/
└── set-password.js
server.js            ← الخادم المحلي / Render
```

عند تحديث `site/page.html` بنسخة أحدث من موقع Claude، يطبّق `tools/site.js` عليها تعديلين صغيرين تلقائيًا. إن تغيّر السطران المستهدفان في الصفحة يتوقف البناء برسالة توضّح السبب.

## المزامنة مع موقع Claude

- **الصفحة** (`site/page.html`) صارت تُطوَّر هنا ولم تعد نسخة مطابقة لموقع Claude، فلا تُستبدل بنسخة موقع Claude.
- **سحب البيانات من موقع Claude** يستبدل ما في `data/db/`، فيمسح أي تعديل تم هنا بعد آخر مزامنة. لا تطلبه إلا إن كان موقع Claude هو الأحدث.

> **تنبيه:** الموقع يحتوي بيانات شخصية للأفراد ومستندات رسمية.

## إضافة جهة جديدة

1. أضف المركز إلى قائمة `CENTERS` في `tools/site.js` (المعرّف بالإنجليزية والاسم)، فتُضبط تلقائيًا مجلدات بياناته ونصوص صفحته.
2. أنشئ `data/units/<الجهة>/db/settings.json`، وفيه الشعار وقوة الورديات (صفر إلى أن تُضبط من «الكادر البشري»).
3. تظهر الجهة تلقائيًا في البوابة بعد النشر.
